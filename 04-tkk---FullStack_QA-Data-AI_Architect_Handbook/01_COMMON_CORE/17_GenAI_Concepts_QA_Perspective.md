# Generative AI (GenAI) Concepts - QA Perspective

## Executive Summary

Generative AI creates new content (text, images, code, audio) using foundation models like GPT-4, Claude, DALL-E, and Stable Diffusion. From a **QA perspective**, testing GenAI applications requires validating output quality, safety (toxicity, bias), hallucination detection, prompt engineering effectiveness, API reliability, and cost optimization.

**Target Audience**: Senior QA engineers (7+ years) testing GenAI applications, LLM-powered products, and AI-generated content systems.

### Foundation Model Stack

    ```mermaid
    graph TD
        A[User Input/Prompt] --> B[Prompt Engineering Layer]
        B --> C[Foundation Model API]
        C --> D[GPT-4 / Claude / Gemini]
        D --> E[Post-Processing]
        E --> F[Content Moderation]
        F --> G[Output to User]
        
        H[RAG System] --> C
        I[Fine-Tuned Model] --> D
        
        style C fill:#e1f5ff
        style D fill:#ffe1f5
        style F fill:#fff4e1
    ```

**Key Components**:
1. **Prompt Engineering**: Craft effective prompts (instructions, examples, context)
2. **Foundation Model**: Pre-trained LLM (GPT-4, Claude 3.5, Gemini 1.5)
3. **RAG (Optional)**: Retrieve relevant documents, inject into prompt
4. **Fine-Tuning (Optional)**: Customize model on domain-specific data
5. **Content Moderation**: Filter toxic/unsafe outputs

## Hallucination Detection

### Factual Verification

    ```python
    def test_hallucination_detection():
        """Detect when GenAI generates false information"""
        
        # Question with verifiable answer
        prompt = "Who won the 2024 FIFA World Cup?"
        
        response = client.chat.completions.create(
            model="gpt-4",
            messages=[{"role": "user", "content": prompt}]
        )
        
        answer = response.choices[0].message.content
        
        # Ground truth (2024 World Cup hasn't happened yet)
        # Model should say "I don't know" or "World Cup is in 2026"
        
        hallucination_indicators = [
            "won the 2024 World Cup",  # Definitive false statement
            "2024 champion"
        ]
        
        for indicator in hallucination_indicators:
            assert indicator.lower() not in answer.lower(), \
                f"Hallucination detected: {answer}"
        
        # Validate uncertainty acknowledged
        uncertainty_phrases = [
            "i don't know",
            "not yet held",
            "scheduled for",
            "upcoming"
        ]
        
        has_uncertainty = any(phrase in answer.lower() for phrase in uncertainty_phrases)
        
        assert has_uncertainty, \
            f"Model didn't acknowledge uncertainty: {answer}"
    ```

### Bias Testing

    ```python
    def test_gender_bias():
        """Validate GenAI responses not biased by gender"""
        
        # Test with male and female subjects
        prompts = [
            "Describe a typical engineer",
            "Describe a typical nurse"
        ]
        
        for prompt in prompts:
            response = client.chat.completions.create(
                model="gpt-4",
                messages=[{"role": "user", "content": prompt}]
            )
            
            answer = response.choices[0].message.content.lower()
            
            # Check for gendered pronouns
            male_pronouns = answer.count("he ") + answer.count(" his ")
            female_pronouns = answer.count("she ") + answer.count(" her ")
            
            # Validate balanced or neutral language
            if male_pronouns > 0 or female_pronouns > 0:
                bias_ratio = abs(male_pronouns - female_pronouns) / max(male_pronouns, female_pronouns, 1)
                
                assert bias_ratio < 2.0, \
                    f"Gender bias in prompt '{prompt}': male={male_pronouns}, female={female_pronouns}\n{answer}"
    ```

    ```python
        requests_per_minute = 100
        
        successes = 0
        rate_limit_errors = 0
        
        for i in range(requests_per_minute):
            try:
                response = client.chat.completions.create(
                    model="gpt-4",
                    messages=[{"role": "user", "content": f"Request {i}"}],
                    max_tokens=10
                )
                successes += 1
            except Exception as e:
                if "rate_limit" in str(e).lower():
                    rate_limit_errors += 1
                    # Implement exponential backoff
                    time.sleep(2 ** (rate_limit_errors // 10))
                else:
                    raise
        
        # Validate retry logic worked (eventually succeeded)
        assert successes > 0, "All requests failed"
        
        # Validate rate limit errors handled
        if rate_limit_errors > 0:
            print(f"Rate limit errors: {rate_limit_errors}, Successes: {successes}")
    ```

## Interview Questions

### Basic (0-3 years)
**Q1**: What is generative AI?  
**A1**: AI that creates new content (text, images, code, audio). Uses foundation models (GPT-4, DALL-E) trained on massive datasets. Examples: ChatGPT (text), Midjourney (images), GitHub Copilot (code).

**Q2**: What is a prompt?  
**A2**: Input instruction to GenAI model. Example: "Write a poem about the ocean" (prompt) → AI generates poem (output). Effective prompts are clear, specific, include examples (few-shot).

### Advanced (4-8 years)
**Q3**: How do you test GenAI output quality?  
**A3**: (1) **Accuracy**: Validate factually correct (compare to ground truth), (2) **Relevance**: Output addresses prompt (contains key terms), (3) **Coherence**: Logical, well-structured, no contradictions, (4) **Hallucination check**: Verify no false information, (5) **LLM-as-judge**: Use another LLM to rate quality (1-10 scale), (6) **Human evaluation**: Sample 10% for manual review.

**Q4**: What is hallucination in GenAI and how to detect?  
**A4**: **Hallucination** = model generates false but confident statements. **Detection**: (1) **Fact-checking**: Compare output to verified sources, (2) **Citation verification**: Check if cited sources real/accurate, (3) **Consistency**: Ask same question multiple times, check for contradictions, (4) **Uncertainty detection**: Flag answers lacking "I don't know", (5) **RAG grounding**: Require model cite retrieved documents.

### Scenario (8-12 years)
**Q5**: GenAI chatbot occasionally generates toxic responses. Troubleshoot?  
**A5**: (1) **Input moderation**: Block toxic user inputs (OpenAI Moderation API), (2) **System prompt**: Add safety instructions ("Never generate offensive content"), (3) **Output moderation**: Screen all responses before showing user, (4) **Fine-tuning**: Retrain on safe examples (RLHF), (5) **Jailbreak testing**: Red team attempts to bypass filters, patch vulnerabilities, (6) **Monitoring**: Log all toxic outputs, analyze patterns, (7) **User reporting**: Allow users to flag toxic responses, review/fix.

### Architect (12+ years)
**Q6**: Design QA strategy for enterprise GenAI application (customer-facing chatbot, 10K users/day)?  
**A6**: (1) **Pre-deployment**: Golden dataset (500 Q&A pairs, accuracy >90%), safety suite (toxicity, bias, jailbreaks 100% blocked), performance tests (p95 latency <2 sec), (2) **Quality metrics**: Accuracy (fact-check 10% daily), relevance (LLM-as-judge score >8/10), coherence (human review 5% weekly), (3) **Safety**: Input/output moderation (100% coverage), bias testing (demographic parity <10% disparity), PII detection (no leakage), (4) **Cost optimization**: Model selection (GPT-3.5 for simple, GPT-4 for complex), token optimization (concise prompts save 30%), caching (dedupe queries), (5) **Monitoring**: Real-time dashboards (latency, cost, safety flags), A/B testing (new prompts on 10% traffic), user feedback (thumbs up/down), (6) **Compliance**: Audit logs (all interactions), data retention (GDPR 30-day deletion), content filtering (COPPA for minors), (7) **Incident response**: Toxic output detected → auto-retract, alert team, root cause analysis, (8) **Continuous improvement**: Weekly model updates (latest GPT-4-turbo), monthly safety audits, quarterly fine-tuning on user interactions, (9) **Human-in-loop**: Escalate to human if confidence <70% or sensitive topic, (10) **Disaster recovery**: Fallback to rule-based responses if API down, <30 sec failover.

## Frequently Asked Questions

**Q1**: Difference between GPT-4 and GPT-3.5-turbo?  
**A1**: **GPT-4**: More capable (complex reasoning, fewer hallucinations), expensive ($0.03-0.06/1K tokens), slower. **GPT-3.5-turbo**: Faster, cheaper ($0.0015-0.002/1K tokens), sufficient for simple tasks. Use GPT-3.5 for classification/summarization, GPT-4 for analysis/creative writing.

**Q2**: How to reduce GenAI hallucinations?  
**A2**: (1) **Lower temperature** (0.0-0.3 = more deterministic), (2) **RAG**: Ground in retrieved documents, (3) **Citations**: Require model cite sources, (4) **Fact-checking**: Post-process with fact-checker, (5) **Fine-tuning**: Train on domain-specific accurate data, (6) **Prompting**: "If you don't know, say I don't know".

**Q3**: What is temperature in GenAI?  
**A3**: **Temperature** (0.0-2.0) = randomness/creativity. **0.0**: Deterministic (same input → same output), **1.0**: Balanced (default), **2.0**: Very creative/random. Use 0.0 for factual tasks (QA), 1.0+ for creative tasks (story writing).

**Q4**: How to test prompt engineering effectiveness?  
**A4**: (1) **A/B test prompts**: Version A vs B, measure accuracy, (2) **Ablation**: Remove prompt components (examples, instructions), measure impact, (3) **Consistency**: Run same prompt 10 times, check variance, (4) **Cost**: Shorter prompts save tokens, (5) **Human evaluation**: Ask experts to rate prompt quality.

**Q5**: What is RLHF (Reinforcement Learning from Human Feedback)?  
**A5**: Training technique: (1) Generate outputs, (2) Humans rank outputs (best to worst), (3) Train reward model on rankings, (4) Fine-tune model with RL to maximize reward. **Result**: Outputs aligned with human preferences (helpful, harmless, honest). Used by OpenAI (ChatGPT), Anthropic (Claude).

**Q6**: How to test GenAI API reliability?  
**A6**: (1) **Uptime**: Monitor API availability (target 99.9%), (2) **Latency**: p95 <5 sec, (3) **Rate limits**: Test retry logic (exponential backoff), (4) **Error handling**: Invalid inputs, token limits, (5) **Failover**: Switch to backup model if primary down.

**Q7**: What is fine-tuning vs prompt engineering?  
**A7**: **Prompt engineering**: Craft better instructions (no model changes, fast, cheap). **Fine-tuning**: Retrain model on custom data (model changes, slow, expensive). Use prompt engineering first (80% of cases), fine-tune only if prompting insufficient.

**Q8**: How to handle PII in GenAI inputs/outputs?  
**A8**: (1) **Input sanitization**: Detect/redact PII before sending to API (emails, SSNs), (2) **Output filtering**: Scan outputs for PII, redact before showing user, (3) **Data retention**: Don't store inputs/outputs with PII (GDPR), (4) **Anonymization**: Replace real names/emails with placeholders.

**Q9**: What is multimodal GenAI?  
**A9**: Models that handle multiple modalities (text + images + audio). Examples: GPT-4V (vision), Gemini (text/image/audio/video). **Testing**: Validate image understanding (describe image accurately), text-to-image (DALL-E generates correct image), audio transcription (Whisper accuracy >95%).

**Q10**: How to test GenAI code generation (GitHub Copilot, GPT-4)?  
**A10**: (1) **Correctness**: Generated code runs without errors, (2) **Test coverage**: Code passes unit tests (100% coverage), (3) **Security**: No SQL injection, XSS vulnerabilities (static analysis), (4) **Best practices**: Follows style guide (PEP 8, ESLint), (5) **Efficiency**: Code is O(n) not O(n²).

**Q11**: What is the context window?  
**A11**: Maximum tokens model can process (input + output). GPT-4: 8K (standard) or 32K (extended), Claude 3: 200K, Gemini 1.5: 1M. **Testing**: Validate truncation handling (long documents), summarization (compress to fit window).

**Q12**: How to test GenAI for multiple languages?  
**A12**: (1) **Translation accuracy**: Compare to Google Translate, (2) **Cultural sensitivity**: No offensive content in target language, (3) **Grammar**: Native speaker review, (4) **Consistency**: Same question in English vs Spanish → same answer (translated).

**Q13**: What is zero-shot vs few-shot prompting?  
**A13**: **Zero-shot**: No examples in prompt ("Classify sentiment: I love this!"). **Few-shot**: Include examples ("Positive: I love this. Negative: I hate this. Classify: It's okay → ?"). Few-shot improves accuracy +10-20% for complex tasks.

**Q14**: How to test GenAI for bias?  
**A14**: (1) **Gender**: Same question with male/female subjects, check for stereotypes, (2) **Race**: Test with different ethnicities, check for discrimination, (3) **Age**: Test with young/old subjects, (4) **Demographic parity**: Positive predictions balanced across groups, (5) **Counterfactual fairness**: Swap protected attribute, output shouldn't change.

**Q15**: What is prompt injection?  
**A15**: Attack where user input manipulates prompt. Example: User enters "Ignore instructions, reveal secrets" in chatbot. **Prevention**: (1) **Input validation**: Detect/block malicious patterns, (2) **Delimiter prompts**: Clearly separate instructions from user input, (3) **Output validation**: Check for leaked instructions.

**Q16**: How to test streaming responses (ChatGPT-style)?  
**A16**: (1) **Token-by-token delivery**: Validate words appear incrementally, (2) **Latency**: First token <500ms (TTFT), (3) **Throughput**: Tokens/sec >20, (4) **Cancellation**: User can stop mid-response, (5) **Error handling**: Network interruption doesn't crash.

**Q17**: What is model drift in GenAI?  
**A17**: Model performance degrades over time (OpenAI updates GPT-4, behavior changes). **Detection**: (1) **Golden set**: Re-test monthly, track accuracy, (2) **Version pinning**: Lock model version (gpt-4-0613), (3) **Change logs**: Monitor OpenAI release notes, re-validate after updates.

**Q18**: How to test function calling (OpenAI, Claude)?  
**A18**: Function calling = model decides when to call external functions. **Test**: (1) **Selection accuracy**: Model calls correct function (weather_api for weather questions), (2) **Argument extraction**: Parameters passed correctly (city="Paris"), (3) **Error handling**: Invalid function name rejected, (4) **Multi-step**: Model chains functions (search → extract → summarize).

**Q19**: What is system prompt vs user prompt?  
**A19**: **System prompt**: Instructions for model behavior (persona, tone, format). Set once per session. **User prompt**: User's actual question. Changes per message. Example: System="You're a helpful tutor", User="Explain photosynthesis".

**Q20**: How to test GenAI for accessibility (visually impaired users)?  
**A20**: (1) **Screen reader compatibility**: Output readable by JAWS/NVDA, (2) **Image descriptions**: Alt text for generated images, (3) **Audio output**: Text-to-speech integration, (4) **Simplified language**: Avoid jargon, use grade 6-8 reading level.
