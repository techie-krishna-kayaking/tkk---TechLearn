# Release Gate Decision

**PASS:** critical data/API/security/AI/NFR tests pass, evidence is current, no open critical defect and post-release monitor/rollback are ready.  
**BLOCK:** any critical failure, missing critical evidence, unapproved reconciliation variance, safety/privacy breach or unavailable rollback.  
**WAIVER:** only named risk owner; documented residual risk, compensating control, expiry and follow-up owner.
