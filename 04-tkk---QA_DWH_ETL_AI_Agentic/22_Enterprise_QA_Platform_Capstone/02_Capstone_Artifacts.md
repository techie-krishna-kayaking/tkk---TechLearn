# Capstone Artifact Checklist

```text
docs/strategy.md                risk, scope, data, environments, gates
tests/data/                     schemas, rules, reconciliation, test data
tests/api/                      contract and integration evidence
evals/ml-llm-rag-agent/         gold sets, rubrics, traces, regression reports
tests/nonfunctional/            SLO, security, performance, recovery plan
reports/release-decision.md     PASS / FAIL / BLOCK with evidence
docs/incident-runbook.md        detection, triage, containment, recovery
```

Do not submit a diagram-only capstone. Every architecture claim needs an executable check, a documented test case or clearly stated monitoring/gate evidence.
