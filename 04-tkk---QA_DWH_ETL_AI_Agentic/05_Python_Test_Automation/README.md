# 05 — Python Test Automation for Data QA

## QA focus

Create maintainable validation utilities, deterministic test data, assertions, reports and CI-friendly exit codes. Python is a means to automate QA evidence, not a software-development track.

## Automation principles

Separate test data, expected results and validators. Make comparison keys explicit. Return actionable mismatch evidence. Keep secrets out of code. Make reruns deterministic.

## Included lab

Review `../shared/automation/src/reconciliation.py` and run its unit tests. Extend it with one business-rule validator and a failing/negative test.

## Interview probe

When would you use database-side SQL validation versus a Python validation framework?
