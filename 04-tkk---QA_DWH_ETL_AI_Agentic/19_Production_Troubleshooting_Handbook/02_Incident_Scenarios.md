# Real-World Incident Scenarios

**Dashboard revenue is 3% high, row counts match:** investigate business key duplicates, join cardinality, currency/rounding, status mapping, cut-off and semantic metric.

**RAG answers cite an old policy:** inspect document ingestion event, index version/freshness, metadata filter, cache and release history; block risky answers or route to source link until repaired.

**Agent took repeated no-op tool calls:** inspect plan/tool trace, argument validation, retry/loop guard and state update; stop execution, apply budget/step cap and add regression.
