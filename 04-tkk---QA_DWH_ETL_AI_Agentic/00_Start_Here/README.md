# Start Here: QA-First Operating Model

## Your role

You are the quality owner around a system built by other teams. Your deliverables are a test strategy, test design, test data, automation, evidence, defects, quality gates and release recommendation.

## The QA loop

`Understand SUT → assess risk → design coverage → prepare data → execute/automate → investigate → report → gate release → monitor production`

## Study routine

For each chapter, write one-page answers to: What must I understand? What can fail? How will I detect it? What evidence proves it? Who decides when it fails?

## Minimum evidence pack

Use the templates in `../shared/templates` to create a strategy, test cases, execution report, defects and gate decision. Never treat a green test run as sufficient without checking coverage and data quality.
