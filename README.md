## 🗺️ What Is This?

**tkk---TechLearn** is a structured, battle-tested interview preparation system for data professionals with 10+ years of experience targeting high-paying roles at product-based companies.

This is **not a course**. It is:
- ✅ Real interview questions with model answers — the exact things asked at Google, Meta, Amazon, Flipkart, Swiggy, Databricks, OpenAI
- ✅ Production-grade code you type and run — not slides, not theory
- ✅ **Runnable, self-checking labs** (DE handbooks 17–22, AI chapters 09–16) — `python3 <file>` asserts its own correctness
- ✅ A structured roadmap — know exactly what to study, in what order, for which role
- ✅ Three complete tracks — pick your target role, follow the plan

> **Honest note on the numbers:** at 10 YOE these salary bands are **Staff/Principal/Lead** territory where total comp is often **equity-heavy**. Deep technical skill is table stakes; the *specialist* chapters and *senior behavioral + negotiation* modules are what move you up a level and up the band. No prep guarantees an outcome — results depend on delivery, the panel, headcount, timing, and how you're leveled and negotiate.

## 🏆 What Big Companies Test — By Role

### Data Analyst (Google / Meta / Swiggy / Zomato / Flipkart)
- Advanced SQL — window functions, sessionization, recursive CTEs
- Product metrics — define North Star, debug metric drops
- A/B testing & **causal inference** — design, sample size, CUPED, diff-in-diff
- Case study — "GMV is down 15%, walk me through your approach"
- Python/Pandas + **analytics engineering (dbt)** — EDA, cohort analysis, semantic layer

### Data Engineer (FAANG / Databricks / Netflix / Stripe / Uber)
- PySpark at scale — query plans, joins, Delta Lake, AQE
- **Data modeling & lakehouse** — Kimball/SCD, Delta vs Iceberg vs Hudi
- System design — design a realtime pipeline with fault tolerance
- DSA — medium difficulty, graphs and DP patterns
- Production troubleshooting + **data quality/governance + DataOps** — skew, schema drift, contracts, CI/CD
- Behavioral — quantified impact, leadership, cross-team influence

### AI Engineer (Google DeepMind / Meta AI / Anthropic / OpenAI / NVIDIA)
- ML theory from first principles — "derive backpropagation"
- Transformers and attention — implement from scratch
- LLMs — RAG, fine-tuning (LoRA/QLoRA, DPO), **inference optimization (KV cache, vLLM, quantization)**
- **Agents & LLM app design** — ReAct, tool calling, eval, guardrails
- ML system design + **distributed training (ZeRO/FSDP, 3D parallelism)**
- DSA — same bar as software engineers; research awareness ("discuss a recent paper")

## 💡 Universal Interview Tips

1. **Clarify before answering** — ask about constraints, scale, data availability
2. **Think out loud** — interviewers want to see your reasoning process
3. **State trade-offs** — "One concern with this approach is..."
4. **Quantify everything** — never say "faster" — say "40% latency reduction"
5. **Mention edge cases** — nulls, duplicates, timezone, schema drift
6. **Business context first** — connect technical choices to business impact
7. **Know your impact** — for behavioral: "I built X, which improved Y by Z%"
